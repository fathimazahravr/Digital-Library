# 📚 Digital Library (MERN Stack)

A full-stack Digital Library web application built using the MERN Stack.

## ✨ Features

- User Registration & Login (JWT Authentication)
- Protected Routes
- Personal Library for Each User
- Add Books
- Edit Books
- Delete Books
- Search Books
- Filter by Genre
- Sort Books
- Favorite Books
- Borrow / Return Books
- Dashboard Statistics
- Reading Progress

## 🛠 Tech Stack

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
- React Router

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- bcrypt

## 🚀 Getting Started

### Backend

```bash
cd backend
npm install
npm start
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```
